# OBJETIVOS-VP-RRII

## Resumen

Plantilla base para el desarrollo de soluciones con SharePoint Framework (SPFx) en Microsoft 365. Este proyecto incluye una estructura organizada para facilitar la creación, despliegue y pruebas de webparts y extensiones personalizadas.

## Versión SharePoint Framework

![versión](https://img.shields.io/badge/version-1.22.2-green.svg)

## Aplicable a

- [SharePoint Framework](https://aka.ms/spfx)
- [Microsoft 365 tenant](https://docs.microsoft.com/sharepoint/dev/spfx/set-up-your-developer-tenant)

> Get your own free development tenant by subscribing to [Microsoft 365 developer program](http://aka.ms/o365devprogram)

## Requisitos previos

- Node.js (versión recomendada: 22.22.2 LTS)

## Pasos iniciales

- Clonar repositorio.
- Asegúrate de estar en la carpeta raíz de la solución.
- En la terminal ejecuta::
  - `npm install -g @rushstack/heft`
  - `npm install`
  - `heft start`

Ver otros comandos disponibles `heft --help`.

## Características

- Estructura modular para componentes, servicios y utilidades
- Integración con Azure Functions y Microsoft Graph (opcional)
- Ejemplo de webpart y configuración
- Scripts para despliegue y empaquetado
